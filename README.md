# Offical repo for "DCLS: Dual-Channel Long-Sequence Retrieval via Interest Enhancement and Popularity-Balanced Supplementation at Tmall"

## Release Notes (Current Version)
The implementation of DCLS is based on our company's customized distributed TensorFlow framework, designed to optimize industrial applications. Due to company policy, this repository provides a carefully extracted and simplified version of the source code. While it is not runnable out-of-the-box, it is intended as supporting material to clearly illustrate the implementation logic of the model architecture and key modules, thereby enhancing the transparency of our method's design.
